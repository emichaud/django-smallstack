## Claude Code notes

Everything above is the tool-neutral `AGENTS.md` (imported, so one file serves every coding agent). The notes below apply to Claude Code only.

- The per-topic skills in `docs/skills/` are also installed as Agent Skills under `.claude/skills/` (symlinks into `.agents/skills/`, regenerated by `make skills-index`). Invoke one with the `Skill` tool, or just read the file it points at — both are the same text.
- `make lint` runs the skill-index check too: a new `docs/skills/*.md` needs a row in `docs/skills/README.md` *and* a `make skills-index` run before the commit hook passes.
