How requests get flagged
  • Probe path — an error response to a path this site never serves and scanners always try (.php, /wp-admin, /.env, /.git, phpmyadmin, cgi-bin, traversal sequences, backup dumps, app-server consoles). Extend with ACTIVITY_PROBE_PATTERNS_EXTRA; exempt a prefix with ACTIVITY_PROBE_IGNORE_PATHS.
  • Scanner agent — a user agent only scanners send (zgrab, masscan, nikto, sqlmap, nuclei, …). Extend with ACTIVITY_SCANNER_AGENTS_EXTRA. Generic tooling such as curl and python-requests is never flagged on its own.
  • Behaviour of an anonymous address — at least half of its requests were 404s across many distinct paths; or a fifth or more were denied (401/403); or django-axes recorded repeated failed logins / a lockout. Only that address's error responses count as evidence — its ordinary traffic is never swept in.
