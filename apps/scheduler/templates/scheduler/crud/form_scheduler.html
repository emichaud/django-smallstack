{% load static %} {% comment %} Custom schedule editor for ScheduledJob. Renders the real Django form fields (so validation + submit are unchanged) but wraps the cadence fields in visual builders: a segmented schedule-type picker with progressive disclosure, an interval builder, and a cron builder — all narrated by a live plain-English summary. Theme-variable-only, palette-correct across all 10 combos. Job identity (name / task / queue / args) is NOT rendered here — the page template (scheduledjob_edit.html) shows it in the identity strip, together with Run now as the page's primary action. This template is the two-rail editor: cadence on the left, behavior + next-runs feedback in the right rail so the preview is visible while the cadence is being edited. {% endcomment %}
