# What is a component?

A component is a **saved card**: one design, drawing one metric, that you build
once and place on as many dashboards as you like. *Server errors as a single
big number. Requests split by method as a pie. Latency as a trend line.*

## What it represents

A metric is a number with a definition. A component is **how that number
looks**: which design draws it, how it's split, what colour it turns, and what
opens when someone taps it. The number itself still belongs to the metric.

The same metric can have several components, each showing it differently, and
one component can sit on many dashboards. Edit the component and every
dashboard showing it updates.

## The designs

| Design | Shows |
|---|---|
| **Single stat** | One number, coloured by its rules. |
| **Grouped stat** | The metric split by a column: the biggest groups as numbers. |
| **Pie chart, Ranked bars** | The same split as shares of a whole, or as bars. |
| **Trend chart** | The metric over time, by day, week or month. |
| **Goals** | The first goals of a goal list and how many are on target. |
| **Calendar** | Upcoming entries from one or more calendars. |
| **Info card** | A status card another part of the app publishes (staff). |
| **Note** | A heading or a few lines of text. |

Your project may add designs of its own. A design that the chosen metric's
data can't support is dimmed in the builder, with the reason.

## How it's set up

**Dashboards → Components → Build a card** opens the builder. A live preview
on the right shows the real card as you go.

1. **Pick a design.**
2. **Say what it shows:** the metric, plus what that design needs, such as the
   column to split by and how many groups.
3. **Style it** (optional): size, alignment, number format, colours. A card
   starts with its metric's format, unit and colour rules. Change one here and
   it changes for this card only.
4. **Drill-down** (optional): which columns appear when someone taps a number.
   **Choose the columns** opens a picker where you tick, order and rename
   them, beside the rows they'll show.
5. **Name it**, tag it, and choose **Personal** or **Shared**.

## How to use it

- **Place it on a dashboard.** Open a dashboard, choose **Edit layout → Add
  card → Saved card**, and pick it. A dashboard can give it its own title.
- **Find it again.** The Components page shows every saved card as a gallery
  of live previews, or as a table with the design, the metric and how many
  dashboards use it.
- **Change it where you see it.** On a dashboard, a card's **⋯** menu has
  **Edit card**: the same builder, in a window over the dashboard.
- **Split one off.** A saved card on more than one dashboard is marked with a
  small link tab. **Make a unique copy** in its menu makes that one placement
  the dashboard's own, with its own metric if you like, and leaves the rest.
- **Reuse it.** **Duplicate** opens the builder with the same settings, ready
  to change.
- **Make it a goal.** A card that boils down to one number has **Add to
  goals** (the target icon). A split or a chart can't be a goal.

## Good to know

- **You don't need a component for every card.** A dashboard can add a Single
  stat or Grouped stat straight from a metric. Build a component when you
  want the same card in more than one place, or want to style it.
- **Editing reaches everywhere.** The builder lists the dashboards a card is
  on, and saving updates all of them.
- **A shared card can only draw a shared metric.** Only staff can share.
- **Deleting a saved card doesn't empty your dashboards.** Each place it was
  used keeps it as an ordinary card, no longer linked to the others.
  Archiving keeps it linked but takes it out of the pickers.
- Like a metric, a card is stored as text (its design, metric and options),
  so an agent can build one for you.
